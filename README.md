## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/zahid111777/Hackthon-Rag-Agent.git
   ```

2. (Optional) Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install dependencies (update if requirements.txt present):
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Navigate to the project directory:
   ```bash
   cd Hackthon-Rag-Agent
   ```

2. Run the main Python script (update if different file structure exists):
   ```bash
   python main.py
   ```
